# 테이블오더 서비스 - 컴포넌트 정의

## 아키텍처 개요
- **패턴**: Layered Architecture (Controller → Service → Repository)
- **구조**: 모노레포 (packages/customer, packages/admin, packages/server)
- **API**: RESTful API
- **상태 관리**: React Context + useReducer

---

## Backend 컴포넌트 (packages/server)

### 1. Auth Module
**목적**: 인증 및 권한 관리
**책임**:
- 관리자 로그인/로그아웃 처리
- JWT 토큰 발급 및 검증
- 테이블 태블릿 인증
- 로그인 시도 제한
- 역할 기반 접근 제어 (슈퍼 관리자/일반 관리자/테이블)

### 2. Store Module
**목적**: 매장 정보 관리
**책임**:
- 매장 CRUD
- 매장별 설정 관리
- 매장 식별자 관리

### 3. Admin Module
**목적**: 관리자 계정 관리
**책임**:
- 관리자 계정 CRUD
- 슈퍼 관리자 → 하위 관리자 생성
- 매장별 관리자 할당

### 4. Table Module
**목적**: 테이블 및 세션 관리
**책임**:
- 테이블 CRUD
- 테이블 세션 시작/종료
- 테이블 초기 설정 (번호, 비밀번호)
- 이용 완료 처리

### 5. Menu Module
**목적**: 메뉴 및 카테고리 관리
**책임**:
- 메뉴 CRUD
- 카테고리 CRUD
- 메뉴 노출 순서 관리
- 메뉴 데이터 검증

### 6. Order Module
**목적**: 주문 처리 및 관리
**책임**:
- 주문 생성
- 주문 상태 변경 (대기중/준비중/완료)
- 주문 삭제 (관리자 직권)
- 주문 내역 조회 (현재 세션/과거 이력)
- 주문 이력 관리 (이용 완료 시 이동)

### 7. SSE Module
**목적**: 실시간 이벤트 전송
**책임**:
- SSE 연결 관리
- 신규 주문 이벤트 브로드캐스트
- 주문 상태 변경 이벤트 전송
- 매장별 이벤트 채널 관리

### 8. Common/Middleware
**목적**: 공통 기능 및 미들웨어
**책임**:
- 에러 핸들링 미들웨어
- 요청 검증 미들웨어
- 로깅 미들웨어
- CORS 설정
- 데이터베이스 연결 관리

---

## Frontend 컴포넌트

### 9. Customer App (packages/customer)
**목적**: 고객용 주문 인터페이스
**책임**:
- 자동 로그인 및 세션 관리
- 메뉴 조회 및 탐색 UI
- 장바구니 관리 (로컬 상태)
- 주문 생성 및 확인
- 주문 내역 조회

### 10. Admin App (packages/admin)
**목적**: 관리자용 매장 관리 인터페이스
**책임**:
- 관리자 로그인/세션 관리
- 실시간 주문 모니터링 대시보드
- 테이블 관리 UI
- 메뉴 관리 UI
- 관리자 계정 관리 (슈퍼 관리자)

---

## 데이터 레이어

### 11. Database (MySQL/MariaDB)
**목적**: 영구 데이터 저장
**책임**:
- 매장, 관리자, 테이블, 메뉴, 주문 데이터 저장
- 세션 및 이력 데이터 관리
- 데이터 무결성 보장
