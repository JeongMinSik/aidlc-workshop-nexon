# 테이블오더 서비스 - 페르소나

---

## Persona 1: 고객 (Customer)

| 항목 | 내용 |
|------|------|
| **이름** | 김민수 (대표 고객) |
| **역할** | 매장 방문 고객 |
| **연령대** | 20~50대 |
| **기술 수준** | 스마트폰/태블릿 기본 사용 가능 |
| **사용 환경** | 매장 내 테이블에 설치된 태블릿 |

### 목표
- 빠르고 편리하게 음식을 주문하고 싶다
- 메뉴를 천천히 살펴보며 선택하고 싶다
- 주문 상태를 확인하고 싶다

### 동기
- 직원을 부르지 않고 바로 주문할 수 있는 편리함
- 메뉴 사진과 설명을 보며 선택할 수 있는 정보 접근성
- 주문 실수를 줄이고 싶은 정확성

### 불편사항 (Pain Points)
- 복잡한 인터페이스로 주문이 어려운 경우
- 주문이 제대로 들어갔는지 확인이 안 되는 경우
- 장바구니가 갑자기 사라지는 경우

## Persona 2: 매장 관리자 (Store Admin)

| 항목 | 내용 |
|------|------|
| **이름** | 박서연 (대표 관리자) |
| **역할** | 매장 운영 관리자 / 매니저 |
| **연령대** | 25~45대 |
| **기술 수준** | 웹 서비스 기본 사용 가능 |
| **사용 환경** | 매장 내 PC 또는 태블릿 (관리자 화면) |

### 목표
- 들어오는 주문을 실시간으로 파악하고 처리하고 싶다
- 테이블별 주문 현황을 한눈에 보고 싶다
- 메뉴를 쉽게 관리하고 싶다

### 동기
- 효율적인 매장 운영으로 인건비 절감
- 주문 누락 방지
- 빠른 고객 응대

### 불편사항 (Pain Points)
- 주문이 들어왔는데 놓치는 경우
- 테이블별 주문 현황 파악이 어려운 경우
- 메뉴 변경이 번거로운 경우

## Persona 3: 슈퍼 관리자 (Super Admin)

| 항목 | 내용 |
|------|------|
| **이름** | 이준호 (대표 슈퍼 관리자) |
| **역할** | 시스템 총괄 관리자 / 사업주 |
| **연령대** | 30~55대 |
| **기술 수준** | 웹 서비스 사용 가능, 기본 IT 이해 |
| **사용 환경** | PC 또는 모바일 (관리자 화면) |

### 목표
- 여러 매장의 관리자 계정을 효율적으로 관리하고 싶다
- 매장별 관리자를 할당하고 권한을 부여하고 싶다

### 동기
- 멀티 매장 운영의 체계적 관리
- 보안을 위한 계정 관리 통제
- 사업 확장 시 빠른 매장 추가

### 불편사항 (Pain Points)
- 매장마다 별도로 계정을 관리해야 하는 번거로움
- 관리자 권한 통제가 어려운 경우
