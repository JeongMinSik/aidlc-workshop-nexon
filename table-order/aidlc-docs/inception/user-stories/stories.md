# 테이블오더 서비스 - User Stories

> **분류 방식**: User Journey-Based  
> **세분화 수준**: 개별 인터랙션별  
> **Acceptance Criteria**: 혼합 (핵심 스토리는 Given/When/Then, 단순 스토리는 간결)

---

## Journey 1: 고객 주문 여정 (Customer Order Journey)

### Epic: 테이블 접근 및 인증

#### US-C01: 테이블 태블릿 자동 로그인
**As a** 고객  
**I want to** 테이블에 앉으면 별도 로그인 없이 바로 주문 화면을 볼 수 있기를  
**So that** 대기 시간 없이 즉시 주문을 시작할 수 있다

**Acceptance Criteria**:
- Given 관리자가 태블릿에 매장/테이블 정보를 1회 설정했을 때
- When 태블릿 브라우저를 열면
- Then 저장된 정보로 자동 로그인되어 메뉴 화면이 표시된다

- Given 자동 로그인이 실패했을 때
- When 인증 오류가 발생하면
- Then 에러 메시지가 표시되고 관리자 설정 화면으로 이동한다

**페르소나**: 고객 (김민수)

---

### Epic: 메뉴 탐색

#### US-C02: 카테고리별 메뉴 목록 조회
**As a** 고객  
**I want to** 카테고리별로 분류된 메뉴 목록을 볼 수 있기를  
**So that** 원하는 종류의 메뉴를 빠르게 찾을 수 있다

**Acceptance Criteria**:
- Given 메뉴 화면에 진입했을 때
- When 카테고리 탭을 선택하면
- Then 해당 카테고리의 메뉴만 카드 형태로 표시된다

- Given 메뉴 목록이 표시될 때
- When 각 메뉴 카드를 보면
- Then 메뉴명, 가격, 이미지가 표시된다

**페르소나**: 고객 (김민수)

#### US-C03: 메뉴 상세 정보 확인
**As a** 고객  
**I want to** 메뉴의 상세 설명과 이미지를 확인할 수 있기를  
**So that** 주문 전에 메뉴에 대해 충분히 파악할 수 있다

**Acceptance Criteria**:
- 메뉴 카드 클릭 시 상세 정보(메뉴명, 가격, 설명, 이미지) 표시
- 상세 화면에서 장바구니 추가 가능
- 닫기/뒤로가기로 목록 복귀

**페르소나**: 고객 (김민수)

#### US-C04: 카테고리 간 빠른 이동
**As a** 고객  
**I want to** 카테고리 간에 빠르게 전환할 수 있기를  
**So that** 여러 종류의 메뉴를 편리하게 탐색할 수 있다

**Acceptance Criteria**:
- 카테고리 탭이 항상 접근 가능한 위치에 표시
- 탭 클릭 시 즉시 해당 카테고리 메뉴로 전환
- 현재 선택된 카테고리가 시각적으로 구분

**페르소나**: 고객 (김민수)

---

### Epic: 장바구니 관리

#### US-C05: 장바구니에 메뉴 추가
**As a** 고객  
**I want to** 원하는 메뉴를 장바구니에 추가할 수 있기를  
**So that** 여러 메뉴를 모아서 한 번에 주문할 수 있다

**Acceptance Criteria**:
- Given 메뉴 목록 또는 상세 화면에서
- When 메뉴 추가 버튼을 터치하면
- Then 해당 메뉴가 장바구니에 수량 1로 추가된다

- Given 이미 장바구니에 있는 메뉴를
- When 다시 추가하면
- Then 수량이 1 증가한다

**페르소나**: 고객 (김민수)

#### US-C06: 장바구니 수량 조절
**As a** 고객  
**I want to** 장바구니에 담긴 메뉴의 수량을 조절할 수 있기를  
**So that** 원하는 만큼 정확하게 주문할 수 있다

**Acceptance Criteria**:
- 수량 증가(+) / 감소(-) 버튼으로 조절 가능
- 수량이 0이 되면 해당 메뉴 자동 삭제
- 수량 변경 시 총 금액 실시간 업데이트

**페르소나**: 고객 (김민수)

#### US-C07: 장바구니 메뉴 삭제
**As a** 고객  
**I want to** 장바구니에서 특정 메뉴를 삭제할 수 있기를  
**So that** 마음이 바뀌었을 때 쉽게 수정할 수 있다

**Acceptance Criteria**:
- 삭제 버튼 클릭 시 해당 메뉴 즉시 제거
- 총 금액 실시간 재계산
- 장바구니가 비면 빈 상태 안내 메시지 표시

**페르소나**: 고객 (김민수)

#### US-C08: 장바구니 비우기
**As a** 고객  
**I want to** 장바구니를 한 번에 비울 수 있기를  
**So that** 처음부터 다시 메뉴를 선택할 수 있다

**Acceptance Criteria**:
- 전체 비우기 버튼 제공
- 확인 후 모든 항목 삭제
- 총 금액 0으로 리셋

**페르소나**: 고객 (김민수)

#### US-C09: 장바구니 로컬 유지
**As a** 고객  
**I want to** 페이지를 새로고침해도 장바구니가 유지되기를  
**So that** 실수로 페이지를 닫아도 선택한 메뉴가 사라지지 않는다

**Acceptance Criteria**:
- Given 장바구니에 메뉴가 담겨있을 때
- When 브라우저를 새로고침하면
- Then 장바구니 내용이 그대로 유지된다

**페르소나**: 고객 (김민수)

---

### Epic: 주문 생성

#### US-C10: 주문 내역 최종 확인
**As a** 고객  
**I want to** 주문 전에 최종 내역을 확인할 수 있기를  
**So that** 실수 없이 정확한 주문을 할 수 있다

**Acceptance Criteria**:
- 주문 확정 전 전체 메뉴 목록, 수량, 단가, 총 금액 표시
- 이 화면에서 수량 수정 가능
- 주문 확정 버튼 명확히 표시

**페르소나**: 고객 (김민수)

#### US-C11: 주문 확정 및 성공 처리
**As a** 고객  
**I want to** 주문을 확정하고 성공 확인을 받을 수 있기를  
**So that** 주문이 정상적으로 접수되었음을 알 수 있다

**Acceptance Criteria**:
- Given 주문 확정 버튼을 클릭했을 때
- When 서버에 주문이 성공적으로 전송되면
- Then 주문 번호가 표시된다
- And 장바구니가 자동으로 비워진다
- And 5초 후 메뉴 화면으로 자동 리다이렉트된다

**페르소나**: 고객 (김민수)

#### US-C12: 주문 실패 처리
**As a** 고객  
**I want to** 주문 실패 시 명확한 안내를 받을 수 있기를  
**So that** 문제를 인지하고 다시 시도할 수 있다

**Acceptance Criteria**:
- Given 주문 확정 버튼을 클릭했을 때
- When 서버 전송이 실패하면
- Then 에러 메시지가 표시된다
- And 장바구니 내용이 유지된다
- And 재시도가 가능하다

**페르소나**: 고객 (김민수)

---

### Epic: 주문 내역 확인

#### US-C13: 현재 세션 주문 내역 조회
**As a** 고객  
**I want to** 현재 식사 세션의 주문 내역을 확인할 수 있기를  
**So that** 무엇을 주문했는지, 총 얼마인지 파악할 수 있다

**Acceptance Criteria**:
- Given 주문 내역 화면에 진입했을 때
- When 현재 테이블 세션의 주문이 있으면
- Then 주문 시간 순으로 정렬되어 표시된다
- And 각 주문별 주문 번호, 시각, 메뉴/수량, 금액, 상태가 표시된다

- Given 이전 세션(이용 완료 처리된) 주문은
- When 주문 내역 화면에서
- Then 표시되지 않는다

**페르소나**: 고객 (김민수)

#### US-C14: 주문 상태 확인
**As a** 고객  
**I want to** 각 주문의 현재 상태를 확인할 수 있기를  
**So that** 음식이 언제 나올지 예상할 수 있다

**Acceptance Criteria**:
- 주문 상태(대기중/준비중/완료) 시각적으로 구분 표시
- 상태별 색상 또는 아이콘 차별화

**페르소나**: 고객 (김민수)

## Journey 2: 관리자 운영 여정 (Admin Operation Journey)

### Epic: 매장 인증

#### US-A01: 관리자 로그인
**As a** 매장 관리자  
**I want to** 매장 식별자와 계정 정보로 로그인할 수 있기를  
**So that** 내 매장의 관리 시스템에 접근할 수 있다

**Acceptance Criteria**:
- Given 관리자 로그인 화면에서
- When 매장 식별자, 사용자명, 비밀번호를 입력하고 로그인하면
- Then 인증 성공 시 관리자 대시보드로 이동한다
- And JWT 토큰이 발급되어 16시간 세션이 유지된다

- Given 잘못된 인증 정보를 입력했을 때
- When 로그인을 시도하면
- Then 에러 메시지가 표시된다
- And 로그인 시도 횟수가 제한된다

**페르소나**: 매장 관리자 (박서연)

#### US-A02: 세션 유지 및 자동 로그아웃
**As a** 매장 관리자  
**I want to** 브라우저를 새로고침해도 로그인 상태가 유지되기를  
**So that** 영업 중 불필요한 재로그인을 하지 않아도 된다

**Acceptance Criteria**:
- 브라우저 새로고침 시 세션 유지
- 16시간 후 자동 로그아웃
- 자동 로그아웃 시 로그인 화면으로 리다이렉트

**페르소나**: 매장 관리자 (박서연)

---

### Epic: 실시간 주문 모니터링

#### US-A03: 실시간 주문 수신
**As a** 매장 관리자  
**I want to** 새로운 주문이 들어오면 2초 이내에 화면에 표시되기를  
**So that** 주문을 놓치지 않고 즉시 처리할 수 있다

**Acceptance Criteria**:
- Given 관리자 대시보드가 열려있을 때
- When 고객이 새 주문을 생성하면
- Then SSE를 통해 2초 이내에 대시보드에 표시된다
- And 신규 주문이 시각적으로 강조된다 (색상 변경/애니메이션)

**페르소나**: 매장 관리자 (박서연)

#### US-A04: 테이블별 주문 현황 대시보드
**As a** 매장 관리자  
**I want to** 테이블별 주문 현황을 그리드 형태로 한눈에 볼 수 있기를  
**So that** 매장 전체 상황을 빠르게 파악할 수 있다

**Acceptance Criteria**:
- Given 관리자 대시보드에서
- When 주문 모니터링 화면을 보면
- Then 테이블별 카드가 그리드 레이아웃으로 표시된다
- And 각 카드에 테이블 번호, 총 주문액, 최신 주문 미리보기가 표시된다

**페르소나**: 매장 관리자 (박서연)

#### US-A05: 주문 상세 보기
**As a** 매장 관리자  
**I want to** 특정 테이블의 주문 카드를 클릭하여 전체 메뉴 목록을 볼 수 있기를  
**So that** 주문 내용을 정확히 확인할 수 있다

**Acceptance Criteria**:
- 테이블 카드 클릭 시 전체 주문 메뉴 목록 상세 표시
- 주문별 주문 번호, 시각, 메뉴/수량, 금액 표시
- 닫기로 대시보드 복귀

**페르소나**: 매장 관리자 (박서연)

#### US-A06: 주문 상태 변경
**As a** 매장 관리자  
**I want to** 주문 상태를 변경할 수 있기를 (대기중 → 준비중 → 완료)  
**So that** 주문 처리 진행 상황을 추적하고 고객에게 알릴 수 있다

**Acceptance Criteria**:
- Given 주문 상세 화면에서
- When 상태 변경 버튼을 클릭하면
- Then 주문 상태가 다음 단계로 변경된다 (대기중→준비중→완료)
- And 변경된 상태가 즉시 대시보드에 반영된다

**페르소나**: 매장 관리자 (박서연)

---

### Epic: 테이블 관리

#### US-A07: 테이블 초기 설정
**As a** 매장 관리자  
**I want to** 테이블 태블릿의 초기 설정(번호, 비밀번호)을 할 수 있기를  
**So that** 고객이 해당 테이블에서 자동 로그인하여 주문할 수 있다

**Acceptance Criteria**:
- Given 테이블 관리 화면에서
- When 테이블 번호와 비밀번호를 설정하면
- Then 16시간 세션이 생성된다
- And 해당 태블릿에서 자동 로그인이 활성화된다

**페르소나**: 매장 관리자 (박서연)

#### US-A08: 주문 삭제 (직권 수정)
**As a** 매장 관리자  
**I want to** 잘못된 주문을 삭제할 수 있기를  
**So that** 고객의 실수나 시스템 오류를 바로잡을 수 있다

**Acceptance Criteria**:
- Given 테이블 주문 상세에서
- When 주문 삭제 버튼을 클릭하면
- Then 확인 팝업이 표시된다
- And 확인 시 주문이 즉시 삭제된다
- And 테이블 총 주문액이 재계산된다
- And 성공/실패 피드백이 표시된다

**페르소나**: 매장 관리자 (박서연)

#### US-A09: 테이블 이용 완료 처리
**As a** 매장 관리자  
**I want to** 고객이 떠난 후 테이블 세션을 종료할 수 있기를  
**So that** 새 고객이 이전 주문 없이 깨끗한 상태에서 시작할 수 있다

**Acceptance Criteria**:
- Given 테이블 관리에서 이용 완료 버튼을 클릭하면
- When 확인 팝업에서 확인을 누르면
- Then 해당 세션의 주문 내역이 과거 이력으로 이동한다
- And 테이블 현재 주문 목록이 비워진다
- And 총 주문액이 0으로 리셋된다
- And 새 고객의 첫 주문 시 새 세션이 시작된다

**페르소나**: 매장 관리자 (박서연)

#### US-A10: 과거 주문 내역 조회
**As a** 매장 관리자  
**I want to** 테이블별 과거 주문 내역을 조회할 수 있기를  
**So that** 이전 매출과 주문 이력을 확인할 수 있다

**Acceptance Criteria**:
- 과거 내역 버튼 클릭 시 과거 주문 목록 표시 (시간 역순)
- 각 주문: 주문 번호, 시각, 메뉴 목록, 총 금액, 이용 완료 시각
- 날짜 필터링 기능 제공
- 닫기 버튼으로 대시보드 복귀

**페르소나**: 매장 관리자 (박서연)

---

### Epic: 메뉴 관리

#### US-A11: 메뉴 등록
**As a** 매장 관리자  
**I want to** 새로운 메뉴를 등록할 수 있기를  
**So that** 고객에게 새 메뉴를 제공할 수 있다

**Acceptance Criteria**:
- Given 메뉴 관리 화면에서
- When 메뉴명, 가격, 설명, 카테고리, 이미지 URL을 입력하고 등록하면
- Then 새 메뉴가 생성되어 고객 화면에 표시된다
- And 필수 필드 미입력 시 검증 에러 표시
- And 가격 범위 검증 수행

**페르소나**: 매장 관리자 (박서연)

#### US-A12: 메뉴 수정
**As a** 매장 관리자  
**I want to** 기존 메뉴 정보를 수정할 수 있기를  
**So that** 가격 변경이나 설명 업데이트를 할 수 있다

**Acceptance Criteria**:
- 메뉴 선택 후 수정 화면 진입
- 모든 필드(메뉴명, 가격, 설명, 카테고리, 이미지 URL) 수정 가능
- 저장 시 즉시 반영

**페르소나**: 매장 관리자 (박서연)

#### US-A13: 메뉴 삭제
**As a** 매장 관리자  
**I want to** 더 이상 제공하지 않는 메뉴를 삭제할 수 있기를  
**So that** 고객에게 정확한 메뉴만 표시할 수 있다

**Acceptance Criteria**:
- 삭제 확인 팝업 표시
- 확인 시 메뉴 삭제 및 고객 화면에서 제거
- 성공/실패 피드백

**페르소나**: 매장 관리자 (박서연)

#### US-A14: 메뉴 노출 순서 조정
**As a** 매장 관리자  
**I want to** 메뉴의 표시 순서를 조정할 수 있기를  
**So that** 인기 메뉴나 추천 메뉴를 상단에 배치할 수 있다

**Acceptance Criteria**:
- 드래그 앤 드롭 또는 순서 번호로 순서 조정
- 변경 즉시 고객 화면에 반영
- 카테고리 내 순서 조정

**페르소나**: 매장 관리자 (박서연)

## Journey 3: 슈퍼 관리자 시스템 관리 여정 (Super Admin Journey)

### Epic: 관리자 계정 관리

#### US-S01: 하위 관리자 계정 생성
**As a** 슈퍼 관리자  
**I want to** 매장별 관리자 계정을 생성할 수 있기를  
**So that** 각 매장에 담당 관리자를 배정할 수 있다

**Acceptance Criteria**:
- Given 슈퍼 관리자 계정 관리 화면에서
- When 사용자명, 비밀번호, 할당 매장을 입력하고 생성하면
- Then 새 관리자 계정이 생성된다
- And 해당 관리자는 할당된 매장에만 접근 가능하다

**페르소나**: 슈퍼 관리자 (이준호)

#### US-S02: 매장별 관리자 할당
**As a** 슈퍼 관리자  
**I want to** 관리자를 특정 매장에 할당/변경할 수 있기를  
**So that** 인사 변동 시 유연하게 대응할 수 있다

**Acceptance Criteria**:
- 기존 관리자의 매장 할당 변경 가능
- 한 관리자가 여러 매장 관리 가능 여부 설정
- 변경 즉시 반영

**페르소나**: 슈퍼 관리자 (이준호)
